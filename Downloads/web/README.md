## 🚀 Quick Start / How to Run

### Method 1: Instant Local View (No Server Required)
Simply double-click `index.html` or right-click and choose **Open with > Chrome / Edge / Firefox / Safari**.

### Method 2: Local HTTP Server (e.g. Node, Python, or VS Code Live Server)
Using Node.js:
```bash
npx serve .
# or
npx http-server -p 3000
```

Using Python:
```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your web browser.
